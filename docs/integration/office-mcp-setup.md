# Office connection setup

The target is persistent shared Brain, skills, files, setup and build access for ChatGPT, Claude and Elsie. The working connector exposes private owner records and content, canonical skills, short-lived file downloads, version-checked record edits, and the same existing Office builders used internally. Builds retain existing provider selection and spending controls. Repeated request IDs cannot dispatch a second paid job. Imported project originals are preserved.

Each external client requires its own explicit Office working authorization. Older read-only grants do not expand automatically. The approval page describes the working permission before it saves that grant. Record access checks the live owner, session, approved client and unrevoked consent on every operation. Raw OAuth table access remains blocked.

Isolated authorization, consent, tenant-isolation, edit-conflict, Finance preservation and duplicate-build tests pass. Source/publication and native acceptance are tracked separately in Reception. Real consent, saved-record reads and writes, build status, token renewal and Elsie handoff tests must pass before any assistant is marked ready. An Office grant does not create a mailbox or Google Drive connection.
