# Add Province or Region

## Trigger and command

Use when adding another province, territory, jurisdiction, service area or geographic region to a multi-region application. Scope: Use configuration-driven architecture; add jurisdiction-specific branding, official sources, standards, geographic rules and routing while preserving shared functionality. Record authoritative sources and effective dates. Boundary: Do not duplicate the entire application unnecessarily. Never guess missing standards, contractors, boundaries or official information. Flag missing information for human review.

Invoke explicitly with `/add-province-or-region`.

## Authority

Follow current Workspace Knowledge at all times, and resolve conflicts using the stated project/workspace authority rules. Read relevant project knowledge before acting. This Skill adds no authorization: review/inspect/check/diagnose is read-only; prepare/draft is proposal-only; implement only the owner-authorized scope. Preserve security, privacy, data integrity, evidence/history, reporter loop-back, jurisdiction separation, ownership/portability and human authority over safety-critical AI.

## Workflow

1. Inspect the shared national core and existing regional configuration. Keep provincial rules out of the national core and preserve jurisdiction separation.
2. Collect verified jurisdiction branding, official sources, standards, identifiers, geography, authorities, responsible organizations, approved queues/contacts and escalation information. Record source versions, dates and correction history.
3. Add the region through configuration/data rather than duplicating the application. Preserve shared reporting, operational review, reporter loop-back, evidence/history and existing regions.
4. Flag missing or conflicting authoritative information for human review; do not activate unsupported routing. Test region selection, boundaries, routing and unaffected existing regional behavior.

## Boundary

Do not duplicate the entire application unnecessarily. Never guess missing standards, contractors, boundaries or official information. Flag missing information for human review.
